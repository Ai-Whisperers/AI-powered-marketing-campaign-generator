# MAGA Documentation

Central documentation hub for the Marketing Campaign Generator.

## Documentation Structure

### `/api/`
REST API documentation for the campaign generator backend.

- **API_OVERVIEW.md** - API endpoints and usage
- **MODELS.md** - Data models and schemas
- **SERVICES.md** - Service layer documentation
- **AUTHENTICATION.md** - Security and auth

### `/tools/`
Documentation for CLI tools and automation scripts.

- **RESEARCH_AUTOMATION_README.md** - Research runner tool
- **example_research_session.md** - Usage examples

### `/architecture/`
System design and implementation documentation.

- **DEVELOPMENT_PLAN.md** - Code architecture overview
- **IMPLEMENTATION_PLAN.md** - Phase 1-4 improvements
- **IMPLEMENTATION_PLAN_V2.md** - Updated implementation plan

## Campaign File Types

Each campaign generates these summary files:

| File | Purpose |
|------|---------|
| `CONSOLIDADO.md` | Full research consolidation |
| `QUICK-REFERENCE.md` | Key facts at a glance |
| `INSIGHTS-CREATIVOS.md` | Creative insights for ideas |
| `RESUMEN-EJECUTIVO.md` | Executive summary |
| `00-RESUMEN-IDEAS.md` | All ideas summary |
