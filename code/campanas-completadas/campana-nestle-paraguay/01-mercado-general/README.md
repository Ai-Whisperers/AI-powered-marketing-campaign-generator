# 01 - Mercado General

## Descripción

Esta carpeta contiene el análisis del contexto de mercado general para Nestlé en Paraguay. Proporciona una visión macro del entorno económico y las oportunidades de crecimiento.

## Archivos

| Archivo | Contenido |
|---------|-----------|
| `market-overview.md` | Tamaño del mercado, tendencias de crecimiento y contexto económico de Paraguay. Incluye proyecciones de crecimiento del PIB (3.6% para 2025) y el rol de Nestlé como hub regional de producción láctea. |
| `market-statistics.md` | Datos estadísticos clave del mercado paraguayo, métricas de consumo y cifras relevantes para la industria de alimentos y bebidas. |
| `cultural-trends.md` | Tendencias culturales emergentes que impactan el consumo, incluyendo la creciente clase media y la demanda de productos de calidad. |

## Hallazgos Clave

- El mercado de bebidas calientes en Paraguay experimentó crecimiento en 2024
- Paraguay se posiciona como hub estratégico para la cadena de suministro de Nestlé en el Cono Sur
- La subsidiaria de Nestlé ha emergido como actor principal en la industria láctea regional
- Compromiso con economía circular y envases 100% reciclables

## Uso

Este análisis sirve como fundamento para entender el contexto macroeconómico antes de desarrollar estrategias de campaña específicas.
