## Estructura de Cada Idea

Cada archivo de idea incluye:

1. **Concepto Central**: Descripción de la idea principal
2. **Insight Clave**: El insight del consumidor que sustenta la idea
3. **Ejecución**: Desglose por canal
   - Social (Instagram, TikTok)
   - OOH (Vallas, paradas de bus)
   - Video (Spots, documentales)
   - PDV (Activaciones en punto de venta)
4. **Puntuación Detallada**: 10 criterios evaluados
5. **Fortalezas y Debilidades**: Análisis FODA de la idea
6. **Recomendación**: Sugerencias de implementación

## Sistema de Puntuación

| Criterio | Descripción |
|----------|-------------|
| Diferenciación | Originalidad vs competencia |
| Relevancia Cultural | Conexión con cultura paraguaya |
| Claridad Insight | Fuerza del insight |
| Ejecutabilidad | Viabilidad de implementación |
| Potencial Viral | Probabilidad de compartir |
| Memorabilidad | Recordación de marca |
| Versatilidad | Adaptabilidad a canales |
| Alineación Marca | Coherencia con Nestlé |
| Potencial PR | Generación de prensa |
| Escalabilidad | Posibilidad de expandir |

## Clasificación por Tiers

- **Tier 1**: Ideas excepcionales (9.0+)
- **Tier 2**: Ideas sólidas (8.0-8.9)
- **Tier 3**: Ideas con potencial (7.0-7.9)
- **Tier 4**: Ideas a desarrollar (<7.0)

## Idea Destacada: Pasos Reales

Campaña que celebra los pequeños logros cotidianos de los paraguayos:
- Conecta con cultura de perseverancia (ñeembotavy)
- Uso inteligente del bilingüismo guaraní-español
- Ejecución integral en todos los canales
- Alta relevancia cultural y escalabilidad

Repositorio de conceptos creativos listos para presentación y desarrollo de producción.
