## Canales de Distribución

| Canal | Descripción | Importancia |
|-------|-------------|-------------|
| Despensas | Tiendas locales pequeñas | Alta (mayoría de compras diarias) |
| Supermercados | Stock, otros retailers | Media-Alta |
| E-commerce | Shop Nestlé Paraguay | Creciente |

## Nestlé Paraguay S.A.

- **Fundación**: 21 de mayo de 1998
- **Antecedente**: Imexpaco del Paraguay SRL (representante desde 1964)
- **Empleados**: +80 en marketing, logística, ventas, finanzas
- **Hub**: Nestlé Business Services Latam (NBS) en Asunción

## Estrategia de Distribución

### Hub Regional
- Planta de Villarrica como centro de producción
- Exportación a: Bolivia, Chile, Uruguay, Perú
- Optimización de infraestructura para lácteos

### E-commerce
- Shop Nestlé Paraguay activo
- Delivery gratuito desde Gs. 100.000
- Integración con estrategia omnicanal
