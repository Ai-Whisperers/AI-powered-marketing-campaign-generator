## Estrategia de SKU

- Reducción de SKUs de bajo rendimiento para mejorar rentabilidad
- Rotación de productos del 22% completada en 2023
- Foco en productos esenciales y básicos
- Operación regional: 7 plantas, +2,200 colaboradores

## Canales de Distribución

- E-commerce: Shop Nestlé Paraguay (delivery gratis desde Gs. 100.000)
- Retail: Principales supermercados
- Tradicional: Despensas y tiendas locales

## Uso

Referencia clave para entender qué productos promocionar y cómo comunicar sus beneficios diferenciadores.
