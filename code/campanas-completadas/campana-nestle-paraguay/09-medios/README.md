# 09 - Medios

## Descripción

Esta carpeta contiene el análisis del ecosistema de medios en Paraguay, incluyendo plataformas sociales, consumo de medios e influencers relevantes.

## Penetración de Redes Sociales

- **82.3%** de población 18+ usa redes sociales (2024)
- **75.2%** de usuarios de internet usa al menos una plataforma

### Top Plataformas en Paraguay (Q2 2024)

| Ranking | Plataforma | Notas |
|---------|------------|-------|
| 1 | Facebook | Mayor alcance, 25-34 años dominante |
| 2 | WhatsApp Messenger | Comunicación principal |
| 3 | Threads | Emergente |
| 4 | Telegram | Creciendo |
| 5 | Messenger | Complemento de Facebook |

### Instagram en Paraguay
- **2.6 millones** de usuarios
- **37.7%** de la población total
- Género: 48.9% mujeres, 51.1% hombres
- Edad principal: 25-34 (31.2%), 18-24 (31%)
