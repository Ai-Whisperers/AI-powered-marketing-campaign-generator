# Siesta Pods: Especificaciones Técnicas y Operativas

**Concepto:** Un oasis de silencio en medio del caos del shopping, diseñado para recargar energía en 15 minutos exactos.

## 1. Diseño Estructural

- **Dimensiones:** 3m (largo) x 2.5m (ancho) x 2.5m (alto).
- **Materiales:**
  - Estructura: Acero negro mate industrial.
  - Paredes: Vidrio templado acústico (doble vidriado hermético) para reducción de ruido de 40dB.
  - Privacidad: Vinilos esmerilados inteligentes (se opacan al entrar) o cortinas de lino pesado color beige/arena.
- **Branding:** Logo Super Spuma iluminado en LED tenue en la parte superior.

## 2. Interior y Equipamiento

- **La Cama:** Sommier _Super Spuma Imperial_ (Queen Size).
- **Ropa de Cama:** Sábanas de 300 hilos, edredón ligero tipo hotel 5 estrellas.
- **Iluminación:** Tira LED cálida (3000K) bajo la cama (efecto flotante) y lámpara de lectura dimmable.
- **Climatización:** Split silencioso mantenido a 21°C constantes.
- **Aromaterapia:** Difusor con esencia de lavanda y eucalipto (propiedad de marca).
- **Audio:** Parlantes embutidos reproduciendo "Ruido Blanco" o "Sonidos de Lluvia" (playlist exclusiva).

## 3. User Journey (La Experiencia)

1.  **Reserva:** Usuario escanea QR afuera del Pod o reserva via App del Shopping. Elige slot de 20 min (15 siesta + 5 limpieza).
2.  **Check-in:** Azafata/o de marca recibe al usuario, le entrega un "Kit de Sueño" (Antifaz descartable, tapones, cupón de descuento).
3.  **La Sesión:**
    - Usuario entra, deja zapatos y bolsas en locker designado.
    - Se acuesta.
    - Una voz suave (grabada) le da la bienvenida: "Bienvenido a tu descanso. Relajate."
    - A los 14 min, la luces suben de intensidad gradualmente (efecto amanecer) para despertar suavemente.
4.  **Salida:** Usuario sale renovado. La azafata le ofrece agua.
5.  **Conversión:** Si el usuario amó la cama, puede escanear un QR interno para comprarla con envío express y 20% OFF.

## 4. Requerimientos de Locación

- Espacio de 4x4 metros (para Pod + Counter de recepción).
- Conexión eléctrica 220V estable.
- Permiso de shopping para estructura semi-permanente (1 mes).
