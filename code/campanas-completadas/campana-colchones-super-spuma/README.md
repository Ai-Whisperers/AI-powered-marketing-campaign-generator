# Proyecto: Campaña "El Despertar" - Colchones Super Spuma

Este directorio contiene todos los activos estratégicos y creativos para la nueva campaña de marca de Colchones Super Spuma.

## Estructura del Proyecto

### 📂 [01-investigacion](./01-investigacion/)

Fundamentos estratégicos de la marca.

- **`brand-identity.md`:** Historia, misión, valores y USPs de Super Spuma.

### 📂 [02-estrategia](./02-estrategia/)

Documentos de venta y planificación.

- **`pitch-deck-structure.md`:** Estructura completa de la presentación para vender la campaña al cliente.

### 📂 [03-ideas](./03-ideas/)

El corazón creativo de la campaña.

- **`100-ideas-master.md`:** La lluvia de ideas original completa.
- **`top-ideas-selection.md`:** Selección curada de las 10 mejores ideas, centradas en la protagonista.
- **`developed-concepts.md`:** **[IMPORTANTE]** Guiones detallados, mecánicas y narrativas de las 10 ideas principales (incluyendo "Tu Mejor Versión", "Siesta Pods", etc.).

### 📂 [04-contenido-rrss](./04-contenido-rrss/)

Planificación de medios sociales.

- **`calendar.md`:** Calendario editorial sugerido para el mes de lanzamiento.

### 📂 [05-recursos](./05-recursos/)

Especificaciones técnicas y visuales.

- **`siesta-pod-specs.md`:** Planos y detalles operativos para la activación en shoppings.
- **`image-prompts.md`:** Guiones visuales listos para generar las imágenes de campaña cuando la capacidad del servidor lo permita.

## Próximos Pasos para Producción

1.  **Casting:** Buscar a la protagonista (MC) basada en la referencia visual proporcionada (ver `03-ideas/top-ideas-selection.md`).
2.  **Rodaje:** Iniciar pre-producción del video "Tu Mejor Versión" usando el guion en `developed-concepts.md`.
3.  **Activación:** Contactar proveedores para cotizar la estructura de los "Siesta Pods" usando las specs de `siesta-pod-specs.md`.
4.  **Diseño:** Ejecutar los prompts de `image-prompts.md` para obtener los Key Visuals finales.
